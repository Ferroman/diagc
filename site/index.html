Diagrams as code, with a local studio

diagc turns diagram sources in your repository into self-contained pages and pictures, and gives you a browser studio to draw them.

curl -fsSL https://raw.githubusercontent.com/Ferroman/diagc/main/install.sh | sh

macOS and Linux, no Node required. With Node 22 or newer: npm i -g @diagc/cli.

Open a live demo Read the tutorial

Features

Pages and pictures

diagc publish writes one self-contained HTML page per diagram, and a PNG. The page folds, zooms and switches views in the browser, with no server behind it.

Host the pages on GitHub Pages, GitLab Pages or any static host. Put the PNG in a README.

  • .diagrams/html/<name>.html one file, with everything inlined
  • .diagrams/html/index.html an index of all the pages
  • .diagrams/static/<name>.png a picture to commit

Publish and share

A local studio

diagc studio opens a browser app against your repository. Draw a diagram there and the studio saves it as a file in the repository. diagc eject turns a drawn diagram into TypeScript.

It runs on your machine against your files: no accounts and no server.

Diagrams as code

A diagram is a TypeScript file, so it diffs, reviews and refactors like the rest of your repository. diagc lint reports what compiles but is probably a mistake.

How it works

  1. Write or draw

    A diagram is a .diagram.ts file under .diagrams/src/. Or draw it in the studio, which writes a .diagram.json. Positions go to a separate .layout.json, so meaning and coordinates land in different diffs.

  2. Compile and validate

    diagc compile checks each source and writes one validated model per diagram. Both ways of authoring meet at that model.

  3. Look, then publish

    diagc studio shows the result and recompiles as you edit. diagc publish writes the HTML pages and the PNGs.

import { model } from '@diagc/core';

// A starter: a customer and one system holding two services and a database.
// `contains` nests, `relate` draws an arrow. The system rests folded, with the
// arrows into it bundled, until you double-click it.
const m = model('shop', { name: 'Shop' });

const customer = m.node('customer', { type: 'person', name: 'Customer' });
const shop = m.node('shop', { type: 'system', name: 'Shop' });

const web = m.node('web', { type: 'service', name: 'Storefront' });
const api = m.node('api', { type: 'service', name: 'Orders API' });
const db = m.node('orders-db', { type: 'database', name: 'Orders DB' });

shop.contains(web, api, db);

m.relate(customer, web, { kind: 'sync', label: 'Browses' });
m.relate(web, api, { kind: 'sync', label: 'Places orders' });
m.relate(api, db, { kind: 'writes', label: 'Order rows' });

export default m;
